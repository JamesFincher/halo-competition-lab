# Experiment 42 — Zero-Init Slider-Gated Attention Head (Architecture-Matched Insert)

User-driven design: new attention capacity encoded behind a learnable scalar slider initialized at exactly 0 — the model is bit-identical to baseline at init (verified), so core weights suffer zero destruction by construction, and RL dials the head in only where it helps. Trains ONLY the slider + head weights with all core weights frozen. Dense instantiation here (SmolLM2-135M, head installed post-layer-27 residual); MoE generalization: per-expert-family keyed gated heads sharing the same code path with expert-conditional gating, for when the competition scales to MoE models. First architecture-insert experiment that cannot degrade the base model at init — the structural answer to the destruction problem exposed by Exps 33-39.
