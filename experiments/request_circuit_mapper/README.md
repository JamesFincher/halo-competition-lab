# Experiment 31 — Request-Type → Layer/Neuron Causal Circuit Mapper

Maps exactly which layers/neurons carry the decision for each semantic request type (violence, cyber, drugs, weather, comms, math, search) via per-type DLA attribution + cross-type exclusivity scoring. Output `request_circuit_atlas.json` is the targeting input for request-routed editing and targeted-circuit RL. Requested directly by user: 'identify what layers and what nodes are affected by what requests so we can target better'.
